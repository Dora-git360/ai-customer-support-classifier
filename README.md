# AI Customer Support Classifier

## Overview

This project is an AI-powered customer support ticket classification workflow built using n8n and Google Gemini AI.

It automatically analyzes incoming customer support requests and classifies them into categories such as Billing, Technical Support, Shipping, or General Inquiry.

## Features

- AI-powered ticket classification
- Automated customer support workflow
- Google Gemini AI integration
- n8n automation
- JSON API support

## Workflow

Webhook
↓
Edit Fields
↓
Google Gemini AI
↓
Return Classified Response

## Technologies Used

- n8n
- Google Gemini AI
- REST API
- JSON
